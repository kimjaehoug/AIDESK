AI Desk · 내 Mac의 일정과 AI 작업을 한곳에서

지원: macOS 13 이상 · Apple Silicon 및 Intel Mac
Python을 따로 설치할 필요가 없습니다.

1. AI Desk.app을 Applications(응용 프로그램) 폴더로 드래그합니다.
2. 응용 프로그램에서 AI Desk를 엽니다.
3. 첫 실행 안내에서 설치된 AI 도구를 확인하고 시작하기를 누릅니다.
4. 위치와 크기를 정한 뒤 배치 완료로 바탕화면에 놓습니다.
   핀 고정은 다른 앱 위에 표시합니다. Dock 아이콘으로 다시 전면에 열 수 있습니다.

플래너와 루틴은 바로 사용할 수 있습니다.
Claude Code / Codex 채팅은 해당 도구를 별도로 설치하고 로그인해야 합니다.
Cursor의 저장된 대화를 볼 수 있으며 이어서 채팅은 Cursor 앱에서 합니다.
ChatGPT는 앱 열기와 요청 복사를 지원합니다. 클라우드 대화를 동기화하지 않습니다.
SSH 서버는 각자의 ~/.ssh/config 설정을 사용합니다.
서버의 Python 3 설치 및 SSH 로그인이 필요합니다.

기록 저장: ~/Library/Application Support/AI Desk
앱을 새 버전으로 바꾸어도 일정과 설정은 유지됩니다.
이 배포본에는 제작자의 일정, 서버 주소, 대화 기록, SSH 키가 들어 있지 않습니다.

현재 배포본은 Apple Developer ID 서명과 공증 전 버전입니다.
다른 Mac에서는 macOS가 실행을 차단할 수 있습니다.
경고 없이 설치하는 정식 배포본은 Developer ID 서명과 Apple 공증 후 제공해야 합니다.

설정 → 시작 안내 · 연결 준비에서 설치 상태를 다시 확인할 수 있습니다.
